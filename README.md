# SKETCH: genome-informed cell cartoons

SKETCH converts genome annotations into consistent, interpretable cell cartoons.
It integrates KEGG Orthologs, pathway/module completeness, and protein localization to infer the presence and spatial organization of metabolic systems, and renders them using a fixed visual grammar.

Unlike pathway mappers or network visualizers, SKETCH produces cell-level representations, enabling direct comparison of metabolic phenotypes across organisms and environments.

Outputs are deterministic, vector-based (SVG), and designed for immediate use in publications.
